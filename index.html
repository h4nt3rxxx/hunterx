About Bountybox

Bountybox is a trial application designed exclusively for bug bounty testing purposes. It showcases secure login via Google OAuth and offers simple features, like showing a user’s name post-authentication. This tool isn’t built for general use or deployment—it’s meant solely for identifying and reporting security flaws in a bug bounty context.

Purpose of Data Access

Bountybox leverages Google OAuth to verify users and retrieve basic details, such as your name and email. This information is accessed only to mimic a login flow for testing needs. We don’t retain your data after your session ends, nor do we disclose it to others, unless legally obligated. This is purely a demonstration for bug bounty research. Check our Privacy Policy for more info.

How to Begin

This is a bug bounty test concept—its features are restricted to evaluation scenarios and not intended as a complete application.
